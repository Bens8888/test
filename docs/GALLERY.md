# Preview gallery

Generated by `tools/make_gallery.sh` with the core renderer, drawn like the editor: blocks
(default look; outline silhouettes with --look 0), spikes, saws, orbs and pads in their colours, portals as bars (gamemode green,
speed orange, gravity/size blue), the floor and ceiling of flying stretches. The bot's path is
white (green while the button is held). Each image is the whole level, wrapped into rows.
